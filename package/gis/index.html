This package has funcionalities to create and manage a database to be used by any model in TerraME.

Types

Type Description
Layer A Layer representing a geospatial dataset stored in a given data source.
Project Project is a concept to describe all the data to be used by a given model.
TerraLib Type to access TerraLib.

Functions

Function Description
Utils Some basic and useful functions to handle file names.

Examples

Example Description
runoff Implementation of a simple runoff model.
