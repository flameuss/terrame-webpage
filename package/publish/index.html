Publishing Model Results

Version: 0.6
License: LGPL-3
Release: 04/30/2025
Authors: Heitor Carneiro and Pedro R. Andrade
Depends: terrame (>= 2.0)

URL: https://github.com/TerraME/publish

This package allows one to export the outputs of different Model scenarios to a web server.

Types

Type Description
Application Creates a web page to visualize the published data.
List A list of View objects.
Report Creates a page with data information.
View View is an object that contains the information of the data to be visualized.
